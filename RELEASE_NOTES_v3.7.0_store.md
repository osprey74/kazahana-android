# v3.7.0 — Store listing ("What's new")

Short release notes for the Google Play "What's new" field (under 500 characters per language).

## English

- New: group chats now show who is speaking. The sender's name appears above the bubble, once per run of consecutive messages, and tapping it opens that person's profile.
- New: the full member list is now fetched and merged, so senders that previously could not be identified are named.
- Fixes: group system messages no longer lose their subject, and reply previews always name the sender.

## 日本語

・新機能: グループチャットで発言者が分かるようになりました。吹き出しの上に送信者名を表示し（連続投稿は先頭のみ）、タップするとプロフィールを開きます。
・新機能: メンバー一覧を別途取得して統合するようにしたため、これまで誰の発言か特定できなかったメッセージにも名前が表示されます。
・修正: グループのシステムメッセージで名前が空欄になる問題と、返信プレビューに送信者名が出ない問題を修正しました。
