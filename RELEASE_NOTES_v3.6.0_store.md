# v3.6.0 — Store listing ("What's new")

Short release notes for the Google Play "What's new" field (under 500 characters per language).

## English

- New: video ALT text is now shown everywhere — an ALT badge on the player plus the description below it, in the timeline, threads, quote posts and notifications.
- New: OP thread numbering badge (e.g. 2/3) next to the timestamp for a run of consecutive posts by the same author.
- Fixes: videos inside quote posts are now displayed, and quote post + video is handled correctly for playback, ALT text and "Save images/videos".

## 日本語

・新機能: 動画のALTテキストをすべての表示面で表示するようになりました。プレイヤー上のALTバッジと直下の説明文を、タイムライン・スレッド・引用投稿・通知で表示します。
・新機能: OPスレッド番号付けバッジ（例 2/3）に対応しました。同じ人の連続投稿で、その中での位置を投稿時刻の横に表示します。
・修正: 引用投稿内の動画が表示されない問題、引用投稿＋動画の再生・ALT表示・「画像・動画を保存」漏れを修正しました。
