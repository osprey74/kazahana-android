# v3.7.1

## English

### Maintenance

- **The credential used to register for push notifications has been replaced.** The app uses it when it registers your device with the kazahana push notification server. Nothing changes in how the app looks or behaves.
- **Please update to this version.** Earlier versions keep receiving notifications for now. After the old credential is retired, they will no longer be able to register a new device or account for push notifications, or to unregister on sign-out.

## 日本語

### メンテナンス

- **プッシュ通知の登録に使う認証情報を入れ替えました。** アプリが kazahana のプッシュ通知サーバーへ端末を登録するときに使うものです。画面や操作に変更はありません。
- **このバージョンへの更新をお願いします。** 以前のバージョンでも当面は通知を受け取れます。古い認証情報を停止したあとは、以前のバージョンでは新しい端末・アカウントのプッシュ通知登録と、ログアウト時の登録解除ができなくなります。
