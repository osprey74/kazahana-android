# v3.7.1 — Store listing ("What's new")

Short release notes for the Google Play "What's new" field (under 500 characters per language).

## English

- Maintenance: the credential used to register for push notifications has been replaced. Nothing changes in how the app looks or behaves.
- Please update: after the old credential is retired, earlier versions will no longer be able to register a new device or account for push notifications.

## 日本語

・メンテナンス: プッシュ通知の登録に使う認証情報を入れ替えました。画面や操作に変更はありません。
・更新のお願い: 古い認証情報を停止したあとは、以前のバージョンでは新しい端末・アカウントのプッシュ通知登録ができなくなります。
