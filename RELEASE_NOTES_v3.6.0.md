# v3.6.0

## English

### New

- **Video ALT text is now shown everywhere.** Videos with ALT text get an **ALT** badge on the player, with the description shown right below it — in the timeline, threads, quote posts, and notifications alike.
- **OP thread numbering badge.** When someone posts a run of consecutive posts of their own, each post now shows its position in that run (for example **2/3**) next to the timestamp.

### Fixes

- **Videos in quote posts are now displayed.** Quoting a post that contained a video previously showed only the text; the video is now played inline in the quote card.
- **Quote post + video ("record with media") is now handled correctly** for playback, ALT text, and **Save images/videos**. Such videos were previously skipped.

## 日本語

### 新機能

- **動画の ALT テキストをすべての表示面で表示**するようになりました。ALT テキストが設定された動画にはプレイヤー上に **ALT** バッジが付き、その直下に説明文を表示します。タイムライン・スレッド・引用投稿・通知のいずれでも表示されます。
- **OP スレッド番号付けバッジ**に対応しました。同じ人が連続して投稿したスレッドでは、その中での位置（例: **2/3**）が投稿時刻の横に表示されます。

### 修正

- **引用投稿の中の動画が表示されない**不具合を修正しました。動画付き投稿を引用すると本文しか表示されませんでしたが、引用カード内で動画を再生できるようになりました。
- **引用投稿＋動画（record with media）**の動画が、再生・ALT テキスト表示・**画像・動画を保存**のいずれからも漏れていた不具合を修正しました。
